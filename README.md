# Bài tập TypeScript OOP - IUH

**Sinh viên:** Đặng Võ Thế Thịnh  
**MSSV:** 23734591

Project gồm lời giải tham khảo cho 30 câu bài tập TypeScript/OOP trong đề.

## Chạy project

```bash
npm install
npm run build
npm start
```

Nếu máy đã cài TypeScript toàn cục, có thể dùng:

```bash
tsc
node dist/index.js
```

## Cấu trúc

- `src/exercises.ts`: lời giải 30 câu.
- `src/index.ts`: tạo dữ liệu mẫu và chạy minh họa cho từng câu.
- `tsconfig.json`: cấu hình TypeScript.
- `package.json`: cấu hình npm.
